# Excel 一括ロック / 年度更新ツール

社内の原価管理業務向けの、**完全オフラインで動く Excel 一括処理ツール**です。
全てを 1 枚の HTML ファイルに同梱しているため、ダブルクリックで開くだけで動きます。
サーバーもインストールも不要です。

**▶ <https://okadamasayuki.github.io/CostManagement/>**

> **読み込んだ Excel が外部へ送信されることはありません。**
> ファイルはブラウザーのメモリー内だけで処理され、社外はもちろん社内サーバーにも送られません。
> 詳しくは [外部通信をしないための仕組み](#外部通信をしないための仕組み) を参照してください。

### 社内で配る場合は「ダウンロードして使う」のがおすすめです

上記の URL は GitHub Pages で公開しているため、**インターネット上の誰でもアクセスできます**
（このリポジトリが public のため）。ツール自体は Excel の中身を送信しませんが、
「社内データを扱うツールを外部サイトから読み込む」ことを避けたい場合は、次の運用にしてください。

1. 上記 URL を 1 度だけ開く
2. **ファイル** タブ →「**ツール本体を保存**」を押す
   → `Excel一括ロック_年度更新ツール.html`（約 1.3 MB）が 1 つだけ保存されます
3. 保存された HTML を**共有フォルダーに置く**（例: `\\server\共有\原価管理 共通\01 ツール\`）
4. 以降は全員がそれを**ダブルクリックするだけ**（ネットワーク接続は不要）

インストールも管理者権限もサーバーも不要です。配るのはこの 1 ファイルだけで、
中に画面・処理・ライブラリがすべて入っています
（外部から読み込む `<script>` / `<link>` は 1 つもありません）。

「ツール本体を保存」はメモリー上のページから復元するため、**この操作でも通信は発生しません**。

次のことは自動テストで毎回検証しています。

- ダブルクリックで開ける `.html` として保存されること
- **日本語・空白を含む深い階層のフォルダー**に置いても開けること
- **ブラウザーを通信できない状態にしても**、読み込み・判定・ロック・保存まで全機能が動くこと
- その間、外部へのリクエストが 0 件であること

なお共有フォルダーから開いた場合でも、Chrome / Edge なら
「**フォルダーを開く**」→「**元のフォルダーへ上書き保存**」がそのまま使えます
（ZIP に書き出して展開し直す必要はありません）。

> **更新するとき**
> 新しい版を配るには、同じ手順で保存し直して共有フォルダーのファイルを差し替えてください。
> ツール側に自動更新の仕組みはありません（外部と通信しないため、意図的にそうしています）。

## できること

| 機能 | 内容 |
| --- | --- |
| **フォルダー一括読み込み** | フォルダーを指定すると、その下の Excel を**サブフォルダーも含めて全部**読み込みます |
| **フォルダー単位の処理** | 「このフォルダー配下だけ」を操作の対象にできます。ツリーのフォルダーをクリックするだけ |
| **セルのロック** | 一部のセルだけをロック / 逆に**指定範囲「以外」を全部ロック**。複数ブック・全シートへ一度に適用できます |
| **シートの保護** | パスワードの有無、許可する操作 (書式変更・並べ替え等) を選んで一括設定 |
| **色分け** | セルを選んで色を押すだけで塗れます。ロックしていないセル (＝入力欄) だけをまとめて塗ることもできます |
| **読み込み時のロック指定** | 読み込んだ時点で「全シートのロックを外す / かける」を選べます |
| **色からロック** | 逆方向。**「この色のセルだけ入力可能にする」**など、既にある色分けからロック設定を起こせます |
| **条件で塗る / ロック** | 「数値が入っているセル」「500,000 を超えるセル」のように、**中身から対象を決めて**一括処理できます |
| **記入欄の自動判定** | 同じ様式を**2 年分**読み込むと、両方を突き合わせて**毎年 値が書き換わっているセル (＝記入欄)** を割り出し、色分けとロックまで一気に行えます |
| **複数ファイルの選択** | 一覧を Shift / Ctrl クリックで選び、その分だけを対象にできます |
| **年度の一括更新** | 2024→2025、2025→2026 … を全シートで**同時に**置換。数式・シート名・ファイル名も対象にできます |
| **手順書** | 行った操作が自動的に手順として記録され、書き出し / 読み込み / 自動実行ができます |
| **保存** | 1 ファイル / 全部を ZIP / 元のフォルダーへ直接上書き (Chrome・Edge) |

UI は Excel に寄せてあります（リボン、シートタブ、数式バー、グリッド）。
グリッド上ではセルの選択・ドラッグ範囲選択・値の編集ができます。

## 使い方

### 初回（1 年目）

1. **ファイル** タブ →「フォルダーを開く」で対象フォルダーを選ぶ
2. **ロック** タブ → 入力させたい範囲を選択して「選択範囲以外をロック」
   （既定で**シート保護まで自動**でかかります。後述）
3. **書式・色** タブ →「ロック解除セルを色分け」で入力欄を目立たせる
   （個別に塗りたいときは、セルを選んでパレットの色を押すだけです。
   斜線の四角を押すと塗りつぶしが解除されます）
4. **年度更新** タブ → 「変更内容を試算」で確認してから「年度更新を実行」
5. **手順書** タブ → JSON と HTML を書き出して保管
6. **ファイル** タブ → 保存

### まっさらな状態から始めたい場合

Excel のセルは**既定で全てロック済み**です。そのため「ここだけ入力させる」
という設定をするとき、既存のロック状態が邪魔になることがあります。

**ファイル** タブの「読み込み時のロック」で「**全シートのロックを外す**」を選んでおくと、
読み込んだ時点で全セルのロックが外れた状態から始められます。
あとは入力させたくない所をロックするだけです。

### 1 つずつ色を付けていられない場合

数百ファイルの同じ場所に色を付けたいときは、次の 2 つが使えます。

**中身から対象を決める** … **書式・色** タブ →「条件を指定して塗る / ロック」
「数値が入っているセル」「500,000 を超えるセル」「"合計" を含むセル」のように
条件で絞り込んで、塗る・ロックする・入力できるようにする、を一括で適用します。

**同じ場所を複数ファイルに** … セルを選んでから、適用先を「読み込んだ全ブック」や
「一覧で選んだブック」にして色を押すと、**すべてのファイルの同じセル**に反映されます。
ファイルの一覧は **Shift クリックで範囲**、**Ctrl クリックで 1 件ずつ**選べます。

### 一部のフォルダーだけを処理したい場合

読み込んだあと、左のツリーで**フォルダーにマウスを重ねて ⊙ を押す**と、
そのフォルダー配下（サブフォルダーも含む）だけが操作の対象になります。
対象になっているフォルダーは 🎯 が付き、サイドバーの上部にも表示されます。

リボンの「適用先」→「フォルダーを指定…」からも選べます。
こちらは実際に存在するフォルダーが件数付きで一覧に出ます。

解除するときは、サイドバー上部の表示にある ✕ を押してください。

指定した適用先は、**ロック・書式・年度更新・文字列の置換のすべてに共通**で効きます。
今どこに適用されるかは**ステータスバーの右側に常時表示**されています。

> **手順書に記録する場合の注意**
> フォルダー指定は**そのままのパス**で手順書に記録されます。
> 翌年フォルダー名が変わる運用（例: `2025年度/` → `2026年度/`）だと一致しなくなります。
> その場合は「ファイル名で指定…」でパターン（例: `*原価*`）を使うか、
> 「読み込んだ全ブック」にしてから、対象フォルダーだけを読み込むようにしてください。
> 一致しなかった手順は実行後に**警告が出る**ので、黙って何も起きないことはありません。

### どこが記入欄か分からない場合（2 年分から自動で判定）

様式が何百種類もあって、「どのセルを主管部が記入しているのか」を
人が一つずつ見ていられないときに使います。

**前年と今年のフォルダーを一緒に読み込んで**、
**書式・色** タブ →「**2 年分を見比べて記入欄を判定**」。

同じ様式のファイルを年違いで組にして、中身を突き合わせます。

| 判定 | 扱い |
| --- | --- |
| 値が**書き換わっている**セル | 主管部の**記入欄** → 色を付けて、ロックを外す |
| 値が**毎年同じ**セル | **様式**（見出し・費目名・固定値）→ ロックする |

誤判定を減らすために、既定で次の 2 つを行っています。

- **年度の数字だけの違いは「変わっていない」とみなす**
  （`2024年度予算` → `2025年度予算` のような見出しを記入欄にしないため）
- **数式は計算結果ではなく、式そのもので比べる**
  （合計欄は結果が毎年変わりますが、記入欄ではないため）

ファイル名・フォルダー名の**年の数字だけが違うもの**を組にします
（例: `2024/予算表.xlsx` と `2025/予算表.xlsx`）。
判定結果は**新しい方のファイル**に反映され、古い方は変更しません。
組にならなかったファイルは実行前に一覧で知らせます。

「判定してみる (試算)」を押すと、変更しないまま件数と
「このセルは 1,234,567 → 2,345,678 と変わっていたので記入欄」という
判定の根拠を確認できます。

> あくまで 2 年分の値の違いからの**推定**です。
> 実行後は画面の色分けで確認し、粗いところは手動の塗り分けで直してください。

### 既に色分けされているファイルの場合

「黄色が入力欄」のような色分けが既にあるなら、範囲を選ぶ必要はありません。

**書式・色** タブ →「**色からロックを設定**」

ファイル内で実際に使われている色を数えて一覧にするので、そこから選ぶだけです。
「選んだ色のセルをロック解除」「選んだ色**以外**をロック」のどちらもできます。
実行前に「試算」で件数を確認できます。

### 2 年目以降

1. **ファイル** タブ →「フォルダーを開く」
2. **手順書** タブ →「手順書を読み込む」で 1 年目の JSON を選ぶ
3. 「すべて試算」で確認 →「すべて実行」
4. **ファイル** タブ → 保存

年度は「**+1 年ずらす**」という相対指定で記録されるので、同じ手順書を毎年そのまま使えます。
半年ごとの運用など、ずらす年数は自由に変えられます。

## Excel の「ロック」の仕組み（重要）

Excel では**すべてのセルに「ロック」属性があり、初期状態ではすべて ON** です。
そしてこの属性は「**シートの保護**」を有効にして初めて意味を持ちます。

そのため「一部のセルだけ入力させたい」場合は、次の 2 段階になります。

1. 入力させたい範囲の**ロックを外す**
2. **シートを保護する**

本ツールの「選択範囲以外をロック」＋「シート保護を有効化」が、この 2 段階に対応しています。
画面右のパネルに、シート保護が無効なままだと警告が出ます。

なお、操作の対象は**データが入っている範囲**です。データのない領域は Excel の既定
（ロック済み）のままなので、「入力欄以外を全部ロックする」という用途では問題ありません。

## 年度置換が「連鎖」しない理由

`2023→2024`、`2024→2025`、`2025→2026` を**順番に**実行すると、
最初の置換で 2024 になった値が次の置換で 2025 になり、
元の 2023 が 2025 まで飛んでしまいます。

本ツールは文字列を**1 回だけ走査して同時に置換**します。
一度置換した位置は二度と評価しないため、この事故は起きません
（`src/excel/yearShift.ts`。テストでも検証しています）。

その他の安全策:

- **対象年の範囲**を指定できます（既定は今年 ±10 年）。範囲外の 4 桁数字は触りません
- **「数字の途中は対象外」**（既定 ON）で、`20240401` のような並びの中の `2024` は置換しません
- **試算（dry run）** で、実際に変更せず件数と内訳だけを先に確認できます

## 外部通信をしないための仕組み

多層で防いでいます。情報システム部門への説明には **セキュリティ** タブをご利用ください。

| 層 | 内容 |
| --- | --- |
| **CSP** | `connect-src 'none'` を HTML に埋め込み、ブラウザー自身が通信を禁止します |
| **通信 API の無効化** | 起動時に `fetch` / `XMLHttpRequest` / `WebSocket` / `EventSource` / `sendBeacon` / `RTCPeerConnection` を使用不能にします |
| **外部リソースなし** | CDN・Web フォント・解析タグを一切使いません。すべて単一 HTML に同梱しています |
| **保存経路** | ブラウザーのダウンロード機能と、ローカルフォルダーへの書き込みのみ |
| **データの保持** | サーバー保存はありません。タブを閉じるとメモリー上のデータは消えます |

GitHub Pages から開いた場合、**最初にページ本体を読み込む 1 回だけ**通信が発生します
（HTML の取得）。その後はファイルを読み込んでも操作しても保存しても、通信は一切発生しません。
自動テストでこの「初回 1 件のみ・以降 0 件」を毎回検証しています。
ローカルに保存したファイルから開いた場合は、その 1 回も発生しません。

**セキュリティ** タブでは、遮断した通信の一覧（発生時刻・宛先）を確認できます。
遮断が 1 件でも起きるとタイトルバーの表示が赤くなります。

### 「サーバーから開いています」と出るが、Excel の中身は送られていないか

**送られていません。** この表示は「**このページ (HTML) をどこから読み込んだか**」を
言っているだけで、扱っているデータの行き先とは無関係です。

受け取り側の記録で確認しています（自動テストで毎回実施）。

| 確認したこと | 結果 |
| --- | --- |
| 配信サーバーが受け取ったリクエスト | **ページ本体の `GET /` 1 件のみ**（本文 0 バイト） |
| そこに Excel の中身が含まれるか | URL・本文とも **1 文字も無い** |
| 持ち出し先を装った「おとりサーバー」が受け取った件数 | **0 件** |

おとりサーバーへは、次の手段すべてで意図的に送信を試みています。
`fetch` / `XMLHttpRequest` / `WebSocket` / `EventSource` / `navigator.sendBeacon` /
`RTCPeerConnection`(WebRTC) / ServiceWorker 登録 / `<img src>` / `<script src>` /
`<form>` の POST 送信 — **どれも 1 件も届きません**。

「ツール本体を保存」で保存される HTML についても、
**読み込んだ Excel の中身は一切含まれません**。
保存元は React が描画する前の HTML（`captureSelf`）で、
保存されたファイルの `<body>` は `<div id="root"></div>` だけです。
これも毎回テストで確認しています。

### ご自身で確認する方法

- ブラウザーで **F12** →「ネットワーク」タブを開いたまま操作しても、通信が 1 件も記録されません
- LAN ケーブルを抜いた状態（完全オフライン）でも全機能が動作します

自動テストでも「外部へのリクエストが 0 件であること」を毎回検証しています。

## 注意していただきたいこと

- **作業前に必ずバックアップを取ってください。**
- 保存すると、ファイルは本ツールが書き直したものになります。
  グラフ・図形・ピボットテーブル・一部の条件付き書式などは、まれに失われることがあります。
  **重要なブックはコピーで試してから本番に適用してください。**
- **`.xlsm` / `.xltm`（マクロ付き）は保存するとマクロ (VBA) が失われます。**
  ファイル一覧に「マクロ」バッジが付き、保存前の確認画面でも警告します。
- シート保護のパスワードは**手順書には保存されません**（安全のため）。実行のたびに入力してください。
- 「元の場所へ上書き保存」は Chrome / Edge でのみ使えます。
  Firefox / Safari では ZIP でのダウンロード保存になります。
- ファイル名を変えて上書き保存する場合、**同じフォルダーに新しい名前で作成**されます。
  元のファイルは残ります。

## 開発

```bash
npm install

npm run dev        # 開発サーバー
npm run build      # dist/index.html（単一ファイル）を生成
npm run typecheck  # 型チェック

npm run test       # エンジンのテスト（Node 上で xlsx を往復させて検証）
npm run test:ui    # ビルドしたHTMLを実ブラウザーで通し実行（Playwright）
npm run test:all   # 両方

npm run fixtures   # 動作確認用のサンプル Excel を sample/ に生成
```

### 配布

`npm run build` して出来た **`dist/index.html` だけ**を配れば動きます。
共有フォルダーに置いても、メールで送っても、各自の PC に置いても構いません。

### GitHub Pages への公開

`.github/workflows/deploy-pages.yml` により、`main` へ push すると自動で公開されます。

公開までの流れ: 型チェック → エンジンのテスト → ブラウザーのテスト
（**外部通信が 0 件であることの検証を含む**）→ ビルド → 公開。
テストが 1 つでも落ちると公開されません。

公開されるのは `dist/index.html`（単一ファイル）だけで、ソースは Pages には載りません。

**初回だけ手動の設定が必要です。**
リポジトリの **Settings → Pages → Build and deployment → Source** を
「**GitHub Actions**」に変更してください。
ワークフローの `GITHUB_TOKEN` では Pages サイトの新規作成ができないため、
ここだけは手作業になります（2 回目以降は不要です）。

設定後に **Actions** タブから「GitHub Pages へ公開」を
`Run workflow` で実行すれば公開されます。

### 実装上の注意点

- **ExcelJS はスタイルオブジェクトをセル間で共有します。**
  同じ書式のセルは内部で同じ `style` オブジェクトを指しているため、
  その場で書き換えると無関係なセルのロックまで変わってしまいます。
  `src/excel/ops.ts` では必ずコピーしてから差し替えています
  （テスト「スタイルを共有しているセルを巻き添えにしない」で検証）。
- **数式を書き換えたときはキャッシュされた計算結果を捨てます。**
  Excel を開いたときに再計算されるようにするためです。
- **共有数式の従属セルは触りません。** マスター側を書き換えれば追随します。
- **ExcelJS の `getRow()` / `getCell()` は「読んだだけ」で行やセルを作ります。**
  比較のように読むだけの処理でこれを使うと、触っていないファイルの
  `dimension` が広がり、保存時に中身が変わってしまいます。
  `src/excel/detectInput.ts` では `findRow()` / `findCell()` を使い、
  古い方のファイルには一切書き込みません
  （テスト「見比べるだけで、古い方のファイルは書き換えない」で検証）。
- **色は 3 通りの指定方法があります** (`argb` 直接指定 / `theme`+`tint` / `indexed`)。
  Excel の「塗りつぶしの色」から標準パレットを選ぶと `theme` になり、RGB が
  入りません。`src/excel/color.ts` で実際の色に解決しています。
  同じ色かどうかの判定は、解決後の RGB ではなく**元の指定を表す key** で行うため、
  独自テーマのブックでも判定は正確です (画面表示の色だけが近似になります)。
